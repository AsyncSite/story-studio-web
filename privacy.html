접근하는 정보와 목적

채널 소유자가 Google OAuth로 허용한 채널 ID와 이름, 영상 메타데이터, 채널의 집계 분석 데이터를 영상 운영과 성과 확인에 사용합니다. 일반 시청자의 Google 로그인을 받지 않습니다.

보관과 접근

OAuth 자격증명은 접근이 제한된 운영 컴퓨터의 별도 파일에 보관합니다. 연결 토큰은 승인된 채널 ID가 일치할 때만 저장합니다. 토큰과 비밀값은 공개 저장소나 공개 문서에 게시하지 않습니다. 연결이 유지되는 동안 자격증명을 보관하며, 삭제 요청 또는 연결 종료 시 운영자가 보관한 자격증명을 삭제합니다.

현재 채널 소유자의 OAuth 동의를 받아 채널 연결을 완료했고, 연결 확인을 위한 채널 조회와 분석 API 읽기 검증을 실시했습니다. 자격증명은 접근 제한된 운영 환경에 보관하며 정기 분석 데이터 수집은 아직 시작하지 않았습니다. 연결 후 저장할 API 데이터는 YouTube 정책에 따라 30일마다 권한 확인과 필요한 갱신·삭제 절차를 적용한 뒤 수집을 시작합니다. 현재 이 자동화는 준비 단계이므로 정기 분석 데이터 수집을 시작하지 않았습니다. 영상 메타데이터는 30일 이내 갱신하거나 삭제하고, 분석·통계의 장기 보관은 30일마다 권한을 확인하는 조건으로 운영합니다. 사용자의 삭제 요청은 접수 후 7일 이내 처리합니다.

제공과 이용 제한

Google API로 받은 사용자 데이터를 판매하거나 광고 목적으로 제공하지 않습니다. 채널 운영 및 사용자가 허용한 기능 제공에 필요한 범위에서만 사용합니다. Google API로 받은 정보의 이용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

이 도구는 YouTube API 서비스를 사용합니다. Google 개인정보처리방침도 확인할 수 있습니다.
